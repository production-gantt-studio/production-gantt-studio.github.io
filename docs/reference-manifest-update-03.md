# Reference Manifest — Update 03

## 変更対象

| 項目 | 内容 |
| --- | --- |
| ユーザーが行う判断 | フェーズの呼称、制作に参加するメンバー、タスクの担当者を案件ごとに設定する。 |
| 追加する操作 | フェーズ名の編集、メンバーの追加・編集・削除、アプリ内の使い方参照。 |
| 既存の真実の源 | `client/src/pages/Home.tsx` の `ProjectData`、LocalStorage、共有URLのJSON。 |
| 維持する動作 | ガント編集、依存関係、CSV/JSON入出力、印刷、共有閲覧、ライト／ダークテーマ。 |
| 追加しない範囲 | 認証、共同編集、外部ユーザー招待、サーバー保存、役割に基づく権限制御。 |

## 変更契約

フェーズ名とメンバーはプロジェクトデータに保存する。既存の保存済みプロジェクトにこの項目がない場合は、広告制作用の既定値で補完する。メンバー名を変更したときは、その名前が設定済みのタスク担当者も同時に更新する。メンバーを削除したときは、対象タスクを「未設定」に戻す。

> メンバー編集は、このブラウザに保存される案件内の担当者リストを変える機能である。アカウントの招待、ログイン、権限付与は行わない。
