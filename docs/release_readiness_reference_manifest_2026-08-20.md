# 最終リリース判定スライド：参照マニフェスト

## 1. 課題の定義

- **成果物**：Production Gantt Studio の最終リリース判定スライド（HTMLスライド）
- **課題種別**：既存UI・最終レビュー文書に基づく意思決定資料
- **読者が決めること**：サンプルを使った限定公開を開始するか、販売・全社展開を保留するか
- **対象外**：今回のスライド作成を理由に、認証方式・DBスキーマ・権限仕様・日程計算の実装を変更しない

## 4. 保存すべき境界

### 変えてはいけないこと

- 案件ごとのデータ隔離、閲覧共有の編集不可、編集者・閲覧者の権限境界。
- 依存日程の連動、親子タスク、保存、アーカイブ、共有URLの既存動作。
- 実装済みと未実装の区別。性能の実測値がない箇所は、リスクとして扱う。

### 資料で明確にすること

- 限定公開は可能である一方、販売・全社展開は実案件の招待・保存受入後に判断する。
- 画面の磨き込みと性能対策は、パイロットの観察結果を使って優先順位を決める。
