# Reference Manifest — Update 07

## Source of Truth

既存の `client/src/pages/Home.tsx` と `client/src/index.css` を、今回のUI・データ・操作の基準とする。保持対象は、LocalStorage保存、閲覧専用共有URL、CSV/JSON入出力、依存関係による日程連動、可変フェーズ、メンバー管理、通常・ゼロスタート画面である。

## 追加する機能

| 機能 | 利用者の判断 | 受入基準 |
| --- | --- | --- |
| 重要タスク・重要日 | 何を優先して確認・連絡すべきか判断する。 | タスク単位の重要指定と、日付単位の重要予定を表示・編集できる。 |
| 期日接近アナウンス | 直近の締切を見落とさない。 | 完了していない近接期日のタスクを集約し、対象タスクを開ける。 |
| 長期表示 | 半年先の制作ロードマップを週単位で把握する。 | 日次と26週表示を切り替えられ、長期では週単位の罫線・タスク位置を表示する。 |
| 小画面ナビゲーション | 狭い画面でも操作入口を失わない。 | サイドバーを潰さず、横スクロール可能な操作レールへ切り替える。 |
