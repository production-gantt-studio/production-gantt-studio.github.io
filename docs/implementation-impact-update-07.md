# Implementation Impact Matrix — Update 07

| 領域 | 区分 | 実装方針 | 保持する境界 |
| --- | --- | --- | --- |
| タスク | live | `isImportant` を任意項目として保存し、既存タスクには既定値を補完する。 | 依存関係、担当者、日程、ステータスを変更しない。 |
| 重要日 | live | 案件データに日付と名称を保存する。 | LocalStorage、JSON、共有URLに案件単位で含める。 |
| アナウンス | live | 重要タスク・重要日・近接期日から派生表示する。 | 通知サービスや外部送信は追加しない。 |
| 長期表示 | live | 既存タスクの日付を週単位へ投影する。 | 日次表示とドラッグ・依存連動を維持する。 |
| レスポンシブナビ | live | 既存ボタンを横スクロール可能な操作レールへ再配置する。 | プロジェクト、メンバー、インポート、ヘルプの操作を削除しない。 |
| 共有ビュー | live | 追加した案件内情報だけを閲覧専用で表示する。 | 他案件、編集、設定の隔離を維持する。 |
