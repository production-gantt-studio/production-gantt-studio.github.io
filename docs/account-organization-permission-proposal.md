# 1人の管理者から販売可能な案件管理サービスへ育てる権限設計

> **推奨結論**：最初はあなたのメールアドレスだけをシステム管理者として登録し、他の人は招待されるまで案件を作れないようにする。その後は、個人ではなく**組織**を単位にデータと契約を分ける。案件内では役割を「編集者」「閲覧者」の2つに絞る。

| 項目 | この提案で決めること |
| --- | --- |
| 現在の開始形態 | あなた1人だけがシステム管理者。 |
| 将来の配布形態 | 社内限定の組織利用と、顧客企業ごとの販売の両方に対応する。 |
| 案件作成 | システム管理者だけが作成する。一般メンバーは勝手に作れない。 |
| 案件の役割 | 編集者／閲覧者の2種類。 |
| 外部共有 | ログイン不要の閲覧リンクを別機能として扱う。案件メンバーとは混同しない。 |
| 現在の状態 | **未実装の将来仕様**。現行のLocalStorage・URL共有を置き換える前提。 |

## 1. 「アカウント」「組織」「案件」を分ける

Googleアカウントのように使うなら、メールアドレスだけで権限を考えない。次の4層を分ける。
