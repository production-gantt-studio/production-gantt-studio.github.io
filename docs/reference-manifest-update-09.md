# Reference Manifest — Update 09

## Source of Truth

`client/src/pages/Home.tsx` のライブタイムライン、`client/src/index.css` の Edit Suite 視覚体系、LocalStorage・JSON・共有URLの案件データを基準とする。既存の依存連動、可変フェーズ、重要日、アナウンス、日次／26週表示、閲覧専用共有を維持する。

| 機能 | 利用者の判断 | 受入基準 |
